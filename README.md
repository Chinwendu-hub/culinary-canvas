## EmailJS contact form

The auto-reply template should set its recipient (`To Email`) to `{{email}}` so the visitor receives the confirmation.

Copy `.env.example` to `.env` and fill in the EmailJS public key, service ID, notification template ID, and auto-reply template ID before starting the app. Do not commit `.env`.
