# Premium Chef Portfolio

## Build
- Create a single polished scrolling portfolio with sticky desktop and mobile navigation.
- Present all supplied biography, specialties, skills, dishes, menu, case study, services, hiring statement, video placeholder, contact details, and footer content.
- Use an ivory, charcoal, and antique-gold editorial design with original chef and food photography.
- Add restrained reveal motion, image hover treatments, an accessible gallery lightbox, expandable dish details, mobile menu, contact-form readiness messaging, and back-to-top control.

## Structure
- Keep repeatable dishes, skills, menu items, services, and case-study steps in editable data collections.
- Build reusable section, card, portfolio, service, and menu patterns so later additions remain straightforward.
- Keep contact submission honest: validate entries and open a prepared email draft until an email service is connected.

## Quality
- Add route-specific search and social metadata plus structured profile data.
- Preserve keyboard navigation, focus states, image descriptions, reduced-motion support, contrast, and touch-friendly controls.
- Verify navigation, lightbox, expansion, form behavior, and desktop/mobile layouts in the running preview.
